# Календарь звонков
Сервис, позволяющий **владельцу** настроить **типы встреч** и дать ссылку **гостям** на свой **календарь**, чтобы они могли забивать свободные **слоты** этими **типами встреч**.

## Основной сценарий
- **Владелец** имеет два интерфейса:
  - UI настройка **типов встреч**, где у каждой есть:
    - Название.
    - Описание.
    - Продолжительность в минутах.
  - UI занятых **слотов** списком с выводом отсортированных информационных блоков о:
    - **Типе встречи**
    - **Имени гостя**.
    - **Продолжительности**.

- **Гость** имеет два интерфейса:
    - UI записи, где можно:
      - В левом блоке выбрать **тип встречи**.
      - В среднем блоке увидеть **календарь** с днями и выбрать день, при этом доступными для выбора будут такие дни, которые:
        - Отстоят от сегодняшнего дня на ближайшие 14 дней вперед.
        - Имеют подходящий оставшийся временной **слот** для выбранного типа встречи.
      - В правом блоке после выбора дня увидеть все свободные временные **слоты**, подходящие для данного **типа встречи**, то есть ее продолжительности и выбрать его.
      - Нажать кнопку «записаться» и во всплывающей модалке ввести имя и нажать кнопку «подтвердить» или «отмена».
    - UI предстоящих встреч, где без выбора гостя видны все предстоящие встречи всех **гостей**, отсортированные, в виде информационных блоков о:
      - **Типе встречи**
      - **Имени гостя**.
      - **Продолжительности**.

## Ограничения
- **Владелец** и **календарь** в системе один, **гостей** в системе сколько угодно.
- **Владелец** - это пользователь, нажавший кнопку «войти как владелец» - это просто тоггл на фронте, так как проект является прототипом. 
- **Гость** - это пользователь, не нажимавший это кнопку или нажавший кнопку «выйти».
- **Гость** идентифицируется вводом имени каждый раз при занимании слота.
- **Слоты**, занятые другими встречами, недоступны для занятия другими встречами.
- **Слоты** на UI нельзя смещать, они заранее нарезаются начиная с 09:00. Свободные **слоты** считает сервер, фронт их только показывает.
